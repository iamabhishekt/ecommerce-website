# Setup for Ecommerce Website Workspace

Welcome to the Ecommerce Website project workspace.

## Architecture

This workspace uses the **Brain** and **Claudify OS** operating environment:
- Universal agent configs, rules, tools, and local state live in `brain/`.
- Discovery symlinks in the root allow any tool (Claude Code, Antigravity, Cursor, Trae, etc.) to discover configuration seamlessly.

## Quick Start

### 1. Claude Code
```bash
claude
> /start
```

### 2. Antigravity / Gemini
Configured via `GEMINI.md` and `.gemini/`. Multi-agent orchestration is enabled.

### 3. Cursor / Trae
Configured via `.cursor/` and `.trae/` rules and commands.
